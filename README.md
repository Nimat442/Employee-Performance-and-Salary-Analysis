# Employee-Performance-and-Salary-Analysis

##  Overview

An Excel data analysis project examining employee performance, salary distribution, departments, and workforce-related KPIs through an interactive dashboard.

##  Objectives

- Analyze employee performance
- Examine salary distribution
- Compare departmental performance
- Identify workforce patterns
- Present HR insights through an interactive dashboard

##  Tools & Technologies

- Microsoft Excel
- PivotTables
- Excel Functions
- Data Visualization
- Dashboard Development

##  Analysis

The dashboard explores:

- Employee performance levels
- Salary distribution
- Department performance
- Job roles
- Workforce KPIs

##  Dashboard

The Excel dashboard is included in the project files.
